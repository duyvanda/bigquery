# Walkthrough: Tự động trích xuất toàn bộ Stored Procedure từ BigQuery `staging_temp`

## 1. Tổng quan công việc
Đã phân tích các script trong thư mục `scratch/` (`check_active_filter.py`, `investigate_sp_jobs.py`, `search_chuanhoa.py`, ...) và xây dựng công cụ Python tự động kết nối BigQuery để lấy toàn bộ thông tin DDL / Definition của tất cả Stored Procedures & Functions thuộc dataset `spatial-vision-343005.staging_temp`.

## 2. Chi tiết các file tạo mới/chỉnh sửa
- **[extract_staging_temp_sps.py](file:///d:/bigquery/scratch/extract_staging_temp_sps.py)**: Script Python kết nối BigQuery, đọc `INFORMATION_SCHEMA.ROUTINES`, tự động làm sạch (clean up) toàn bộ các dòng trống thừa (`\n\n\n...`) giữa các cột SELECT, mệnh đề DECLARE/SET/WHERE/CASE, và xuất ra file SQL chuẩn hóa, gọn đẹp.
- **Thư mục đầu ra**: `d:\bigquery\staging_temp_extracted`

## 3. Kết quả thực thi
- **Tổng số Routines tìm thấy trên BigQuery (`staging_temp`)**: 132 Routines (Stored Procedures & Functions).
- **Chuẩn hóa định dạng**: Loại bỏ hoàn toàn các ký tự xuống dòng thừa do BigQuery DDL sinh ra (ví dụ: file `api_doanh_so_theo_ke_hoach_crs.sql` giảm từ **208 dòng** xuống còn **92 dòng** vô cùng gọn đẹp và dễ đọc).
- **Thành công**: 132/132 file SQL được lưu kèm thông tin Header chuẩn.
- **Manifest JSON**: `d:\bigquery\staging_temp_extracted\manifest_routines.json`.
